# Portfolio

Single-file portfolio site, served with GitHub Pages: https://godsmasher.github.io/my-portfolio/

No framework, no build step, no cookies. The demo videos in `assets/` are recorded from the hosted demos of
[birdie-platform](https://github.com/GodSmasher/birdie-platform) and [botworks](https://github.com/GodSmasher/botworks)
with each repo's `npm run demo:record`.
